SPEC 3c — Correct the Tissue Translocation decomposition and narrative
Background / rationale. The SPEC 3b narrative attributes the Tissue Translocation shift solely to the length-slope fix and dismisses the volume/area fix as immaterial: it states that Tissue Translocation "P(RQ>1) is 68% under the legacy volume/area slope, i.e. essentially unchanged from the corrected value." The corrected value is 30.9%, so 68% → 30.9% is not "essentially unchanged" — it is a >2× reduction. Mechanistically, tissue-translocation/oxidative-stress alignment is surface-area-weighted, so it is sensitive to the a.sa correction (1.3 → 2.3); the steeper corrected a.sa raises the mean-surface-area threshold and lowers the RQ. The claim that Tissue Translocation is number/size-only and insensitive to the SPEC 1b fix is therefore wrong.
Implementation:
1.	In the Tissue Translocation decomposition, add a fourth one-at-a-time reversion row isolating the surface-area slope (a.sa reverted to cumulative, all else corrected), alongside the existing exposure-CF, length-slope, and volume/area rows. Report RQ_p50, RQ_p95, P(RQ>1) for HC5.
2.	Rewrite the narrative to state that the a.sa correction is a material driver of the Tissue Translocation change (~68% → ~31% P(RQ>1) at HC5), because translocation uses surface area as its ERM; remove the "essentially unchanged" claim.
3.	State the corrected qualitative conclusion explicitly: after both fixes, river Tissue Translocation HC5 is below threshold at the median (RQ ≈ 0.21, P ≈ 31%), while Food Dilution remains risk-dominant.
Acceptance criteria: The Tissue Translocation decomposition table has an a.sa-reversion row; the narrative attributes the shift to both the length-slope and surface-area-slope fixes; no residual "essentially unchanged" statement contradicts the table.
